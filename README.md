# Libros Interactivos — Centro Educativo Salomé Ureña

Versión interactiva de la colección **Libro Abierto** del Ministerio de Educación de la República Dominicana (MINERD) — Lenguas Extranjeras (Inglés y Francés), todos los grados que se imparten en el centro.

Cada libro muestra sus páginas tal como en el original (imágenes, diseño, iconos), con zonas de audio invisibles sobre todo el texto en el idioma correspondiente: al hacer clic se reproduce una grabación de voz neuronal pre-generada, funciona sin conexión a internet.

Abre [`index.html`](index.html) para ver el índice completo de libros.
